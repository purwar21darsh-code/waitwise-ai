# WAITWISE AI logo asset

`public/logo/waitwise-mark.svg` is the editable source. `public/logo/waitwise-mark.png` is the 512 × 512 PNG deliverable (transparent padding not required; file size is below 3 MB).

## Generation specification

- Rounded deep-navy square, mint green shape suggesting a waiting loop, and a navy check mark.
- Keep the geometry simple so the icon remains clear at 32 px.
- Brand colors: `#15233A` navy and `#6DD6A3` mint.
- Do not add a coin, token, or rising-price symbol.
- Export PNG at 512 × 512 and 1024 × 1024; keep each file under 3 MB and preserve the SVG source.

The PNG in this folder is generated from the SVG source and can be regenerated with an SVG-capable image editor or renderer. It is a logo asset, not a product screenshot.
